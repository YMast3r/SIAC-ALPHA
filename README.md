# SIAC-ALPHA

Sistema de Administración de Condominios. Aplicación web para la gestión 
de condominios, incluyendo el control de residentes, pagos y reportes 
administrativos.

## Tecnologías

- **Backend:** Node.js
- **Frontend:** Handlebars (motor de plantillas)
- **Base de datos:** SQL

## Funcionalidades

- Gestión de residentes y unidades habitacionales
- Registro y consulta de pagos
- Panel administrativo con reportes

## Instalación

\`\`\`bash
npm install
npm start
\`\`\`
